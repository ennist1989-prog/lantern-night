# Pocket Rogue — Art

Owned by Pocket Art (art director for the Pocket Rogue project).

Planned contents:

- `style-guide.md` — pixel art style guide: resolution, sprite sizes, palette and color caps, outline and highlight rules, animation frame counts, UI specs.
- `palette/` — master palette files (hex list, .gpl / .png swatches).
- `asset-list.md` — prioritized asset list: classes, enemies, bosses, tile sets, UI, icons, lobby screens.
- `prompts/` — AI image prompt templates and per-asset prompts.
- `reviews/` — pixel-lint review notes on submitted art.

Reference: `pocket-games/rogue-legend-brief.md` (Pocket Research).
